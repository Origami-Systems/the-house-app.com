This update focuses on the new Point Presets and cleaning them up to be more user friendly.

## Improvements

- Redesigned the Point Options pages to make creating and editing options easier.
- Added a visual message editor for inserting answers into point history.
- Added previews so you can test a point option before saving it.
- Improved validation, labels, navigation, and error messages.

## Bug Fixes

- Fix the Guest invites card being smaller than it should be.
- Fixed the tab bar not fully disappearing when in presentation mode.

## Bugs and Feedback

As always, if you encounter any bugs or have suggestions for improving The House App, we'd love to hear from you. You can submit feedback from the **Account** page.
