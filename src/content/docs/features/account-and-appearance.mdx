# Account and appearance

## Description

Account settings collect the controls that apply to the signed-in user. Users can switch the app's theme, open security settings, manage notifications, install the app when supported, reach support forms, or sign out. Some security controls open in the connected account application.

## Open account settings

Use the account button in the app header to open **Account Settings**.

## Buttons and controls

- **Install as App for Notifications** starts installation on supported browsers. On other browsers, it opens the installation guide.
- **Manage Notifications** opens notification choices after the app has been installed.
- **Toggle theme** switches between the light and dark themes.
- **Manage Security Settings** opens the built-in security page.
- **Open the Account App** opens the separate account application in a new tab.
- **Report Bug** opens the bug report form.
- **Give Feedback** opens the feature feedback form.
- **Log Out** ends the current session.

Guest users should be careful with **Log Out**. They need another valid invitation to regain access.
