# Event attachments

## Description

Event attachments keep schedules, forms, images, and other event files beside the calendar entry they belong to. Anyone who can view the event can download its attachments. Administrators manage the files.

## Download an attachment

1. Open **Calendar**.
2. Select the event.
3. Find the **Attachments** card.
4. Select **Download** beside the file you want.

The Attachments card only appears when the event has files.

## Add an attachment

1. Open the event as an administrator.
2. Select **Edit Event**.
3. Select **Add Attachment**.
4. Choose a file.
5. Select **Upload**.

Supported files include PDF, Word, Excel, common image and video formats, text, ZIP, RTF, CSV, SVG, and WebP files. A filename cannot contain `..` or `/`.

## Delete an attachment

On the event editing page, select **Delete** beside the attachment. This removes the file from the event.
