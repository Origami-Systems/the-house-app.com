# Quick Add users

## Description

Quick Add reduces repeated typing when an administrator creates users whose email addresses follow the same naming pattern. It builds the username and email address from the person's name and an email domain.

## Create a user with Quick Add

1. Open **Admin > Add User**.
2. Select **Quick Add**.
3. Enter the first and last name.
4. Enter the email domain, such as `school.edu`.
5. Choose the user type and house.
6. Choose a name prefix for a dean or administrator if needed.
7. Check the generated email and username in the **Data** card.
8. Select **Create User**.

Quick Add creates usernames in `first.last` format and combines that username with the email domain. Use the regular Add User form when the account needs a different username or email address.
