# Guest group management

## Description

Guest group management gives administrators a way to provide temporary access to many people at once. Administrators can create groups and generations, issue invitations, and download or print QR codes for distribution. Guest groups can be reviewed and archived when their access is no longer needed.

## Create a guest group

1. Open **Admin > Guests**.
2. Select **Create**.
3. Enter a name and complete the access settings shown in the form.
4. Submit the form to create the group.
5. Select the new group to manage it.

## Create access for a group

1. Open a guest group.
2. Select **Create New Generation** when you need a new set of guest identities.
3. Select **Create New Invite** to create a shareable invitation.
4. Give the invite a useful name and description, then create it.
5. Open the invite to display its link and QR code.

## Invitation controls

- The copy control copies the invitation value shown beside it.
- **Download QR Code** saves the QR code as an image.
- **Print QR Code** opens a print-ready version in a new window.
- Generation arrows move between older and newer guest generations.

## Archive guest access

Use the action menu on a guest group or guest entry to start archiving it. Review the confirmation carefully. Archived access should no longer be handed out, even if an older QR code still exists.
