# Announcements

## Description

Announcements give the organization a central place for news and updates. Users can browse published announcements, and administrators can create, edit, or delete them. New announcements can also appear as in-app or device notifications when a user has enabled notifications.

## Read announcements

1. Select **Announcements** in the main navigation.
2. Scroll through the current page.
3. Use the pagination controls to move between pages when older announcements are available.

Each announcement shows its title, message, author, posting time, and whether it was edited.

## Create an announcement

1. Select **Create**. Students and guest groups do not see this button.
2. Administrators can choose a house or leave **All Houses** selected.
3. Enter a title and message.
4. Select **Send**.

## Edit or delete an announcement

1. Open the three-dot **Actions** menu on the announcement.
2. Select **Edit**, change the title or message, then select **Update**.
3. To remove it instead, select **Delete Announcement** and complete the confirmation.

The Actions menu appears for the announcement's author and for administrators.
