# Presentation mode

## Description

Presentation mode opens a simplified game display for a projector, television, or second screen. It keeps the live leaderboard or bracket visible without the usual app navigation, making it easier for an audience to follow a competition as scores and results change.

## Open a separate presentation window

1. Open **Standings** while a game is active.
2. Open the **Games** menu.
3. Select **Detach View Game**.
4. Move the new window to the projector or audience display.
5. Keep the management screen open in the original window.

The detached window receives live score, bracket, cheering, and game-end updates. If the browser blocks the new window, allow pop-ups for The House App and try again.
