# House management

## Description

House management lets administrators add and maintain the houses used throughout the app. An administrator can set a house's name, color, description, and other identifying details, update an existing house, or archive a house that is no longer active.

## Add a house

1. Open **Admin > Add House**.
2. Enter the house name.
3. Add an optional description and motto.
4. Choose the house color.
5. Select **Add House**.

## Edit a house

1. Open **Admin > Edit Houses**.
2. Select the house you want to change.
3. Update its name, color, description, or motto.
4. Use the form's save control.

## Archive a house

Select **Archive House** in the Danger Zone, then complete the confirmation. The house moves to **Admin > Archives > Houses** and no longer appears with active houses.
