# Point presets

## Description

Point presets help authorized users award common types of points without entering the same information each time. Administrators can define the preset name, point amount or choices, extra parameters, and the message created from those values. Presets can be tested before they are saved, then edited or deleted later.

## Create a preset

1. Open **Admin > Add Preset**.
2. Enter a short preset name.
3. Choose an **Awarding Points Method**.
4. Choose which user types may use the preset.
5. Enter the amount, predefined choices, or custom amount settings required by that method.
6. Build the message shown when someone awards points.
7. Turn on **Show Advanced Options** if you need approval rules, enabled status, or extra parameters.
8. Use **Test Preset** and complete the sample point form. The test does not award real points.
9. Select **Add Preset** after the test succeeds.

## Awarding methods

- **Fixed Amount** always awards the amount entered in the preset.
- **Predefined Options** lets the user choose from the values in the options list.
- **Custom when adding** asks the user to enter an amount each time.

## Advanced controls

- **Enabled** controls whether the preset can be used.
- **Requires Admin Approval** sends eligible dean submissions to Pending Points.
- **Add Parameter** adds information the user must supply when awarding points.
- **User Types with Access** controls whether administrators, deans, and leaders can use the preset.

## Edit or delete a preset

Open **Admin > Edit Presets** and select a preset. Change its name, status, type, amount, approval rule, access, options, or message, then save the relevant form. Parameters cannot be edited on an existing preset. Recreate the preset to change them. **Delete Preset** removes it.
