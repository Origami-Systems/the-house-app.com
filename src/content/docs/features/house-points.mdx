# House points

## Description

House points record the awards and deductions that make up a house's score. Users can browse a house's point history and open an entry to see its value, reason, recipient, and comments. Authorized users can add points, and administrators can review or delete individual entries.

## View point history

1. Open **Home** or **Houses**.
2. Open the house you want to review.
3. Select the points feed to see all entries.
4. Select an entry to see the amount, date, reason, and comments.

## Award points

1. Open the receiving house's profile.
2. Select **Add Points**.
3. Choose a point preset.
4. Select **Add Points** again.
5. Fill in any extra fields requested by the preset. Depending on the preset, you may need to select or enter the number of points.
6. Select **Add Points** to submit the award.

Some awards made by deans require administrator approval. In that case, the form asks for an optional note and sends the award to the pending list instead of changing the standings immediately.

## Point detail controls

- **Options** opens the actions available for the selected entry.
- **Send Comment** adds a comment when the organization allows point comments. Guest groups cannot comment.
- **Delete Points** removes the point entry. This action is only available to administrators.
