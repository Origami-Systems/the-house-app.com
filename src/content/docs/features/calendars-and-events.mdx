# Calendars and events

## Description

Calendars help users find upcoming organization events. Each event can include a title, time, description, and downloadable attachments. Administrators can create and manage calendars, add events, edit event details, attach files, and remove events that are no longer needed.

## Find an event

1. Select **Calendar** in the main navigation.
2. Change the displayed month if needed.
3. Select a date to show its events below the calendar.
4. Select an event to open its details.
5. Select **Download** beside an attachment to save it.

The Calendar navigation item only appears when your role has access to at least one calendar.

## Add an event

1. Select a date, then select **Add Event**. Only administrators see this button.
2. Enter a title and optional description.
3. Leave **All Day** on and choose start and end dates, or turn it off and choose exact start and end times.
4. Choose the calendar that should contain the event.
5. Select **Add**.

The end must be later than the start.

## Edit an event

1. Open the event and select **Edit Event**.
2. Change the event fields and save the form.
3. Select **Add Attachment** to upload a file.
4. Use **Download** or the attachment removal control to manage existing files.
5. Select **Delete Event** to remove the event, then confirm the action.

## Manage calendars

Open **Admin > Calendar Settings** to create a calendar or select an existing calendar to edit it. **User Types with Access** controls who can see it. Administrators must remain in the access list. **Delete Calendar** removes the calendar and all of its events after confirmation.
