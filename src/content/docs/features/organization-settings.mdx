# Organization settings

## Description

Organization settings let administrators change the organization's name and control how the house system works. Available options include point comments, dean roles, comment cleanup, house-page wording, and whether deans or student leaders may award points across all houses.

## Change organization settings

1. Open **Admin**.
2. Find the organization settings card.
3. Change the name or switch the settings you want to update.
4. Use the form's save control to apply the changes.

## Settings explained

- **Allow comments on points** lets eligible users post comments on point entries.
- **Use Dean User Type** enables dean-specific roles and controls.
- **Delete deleted user's comments** removes a user's comments when that user is deleted.
- **Show 'House' in House Page** includes the word "House" in house page headings.
- **Allow Deans to add points to all houses** extends dean point access beyond their assigned house.
- **Allow Leaders to add points to all houses** does the same for student leaders.
- **Advanced Settings** expands the cross-house point controls.

The same settings also appear on the organization management page.
