# Live leaderboard games

## Description

Live leaderboard games let houses compete in a real-time points contest. A shared game view keeps scores up to date as an administrator adds or removes points, hides or reveals results, and moves the game to its podium. When cheering is enabled, audience members can send cheers during the game.

## Start a leaderboard game

1. Open **Standings** as an administrator.
2. Select **Start Game**.
3. Enter a game name.
4. Turn **Allow Cheering** on or off.
5. Choose **Leaderboard** as the game type.
6. Select **Start Game**.

## Manage scores

1. Open **Games > Add Points** from Standings.
2. Use **Search** to find a house, or use **Sort By** to order houses alphabetically or by score.
3. Select a house.
4. Enter a point amount and choose **Add** or **Remove**.
5. Select **Add Points** to update the score.

## Buttons and controls

- **Hide Points** covers the scores on the audience view. The button changes to **Show Points** while scores are hidden.
- **Cheer!** sends one cheer for the signed-in user's house. The button is available only when cheering is enabled and the user belongs to a house. There is a two-minute wait between cheers.
- **End Game** finishes the game and records the final result.
- **Back** on the podium returns to Standings.
