# Bracket games

## Description

Bracket games organize houses into head-to-head matches and show their progress through each round. Administrators can select match winners and manage the bracket, while participants can follow the live bracket and final podium from a presentation-friendly view.

## Start a bracket game

1. Open **Standings** as an administrator.
2. Select **Start Game**.
3. Enter a game name and choose whether to allow cheering.
4. Choose **Bracket** as the game type.
5. Select **Start Game**. The app opens the bracket management screen.

The Bracket option appears only when the organization has an even number of houses greater than two.

## Manage the bracket

1. Find the match you want to complete.
2. Select the winning house on the match card.
3. Confirm each match until a champion reaches the final position.
4. Use **Games > View Game** from Standings to check the audience view.
5. Select **End Game** when the bracket is complete.

Changing a selected winner updates the later bracket rounds, so check the match before moving on.
