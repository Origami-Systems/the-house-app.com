# User management

## Description

User management lets administrators add people, assign their house and role, edit account details, reset passwords, and archive accounts. A quick-add workflow is available for entering multiple users with less repetition.

## Add a user

1. Open **Admin > Add User**.
2. Enter the email address, first name, last name, and username.
3. Choose the user type and house.
4. For a dean or administrator, choose a name prefix if needed.
5. Select **Add User**.

Entering an email address fills the username with the part before the `@` when the username is still empty. You can edit the result before submitting.

## Use Quick Add

1. Select **Quick Add** on the Add User page.
2. Enter the first name, last name, and email domain.
3. Choose the role, house, and optional name prefix.
4. Check the generated email and username in the **Data** card.
5. Select **Create User**.

## Edit a user

Open **Admin > Edit Users**, then select a user. You can change the house, user type, name prefix, first name, and last name. Use the form's save control to apply the changes.

## Other controls

- **Reset Password** sends the selected user through the password reset process after confirmation.
- **Archive User** removes the user from the active list after confirmation.
- **Guests** opens the separate guest group tools.
