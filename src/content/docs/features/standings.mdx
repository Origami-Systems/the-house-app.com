# Standings

## Description

Standings rank houses by their current point totals. The page gives students and staff a shared view of the competition and provides access to an active game when one is running. Administrators can also start, manage, present, or end games from this area.

## How to use it

1. Select **Standings** in the main navigation.
2. Read the ordered list to compare current house totals.
3. If a game is active, select **View Game** to follow it.

The standings update while the page is open when new point totals arrive.

## Administrator controls

- **Start Game** opens the game setup form when no game is active.
- **Games** opens the actions for the active game.
- **View Game** opens the audience view.
- **Add Points** opens the score controls for a leaderboard game.
- **Manage** opens winner selection for a bracket game.
- **Detach View Game** opens the audience view in a separate window.
- **End Game** finishes the active game and returns the app to the regular standings.
