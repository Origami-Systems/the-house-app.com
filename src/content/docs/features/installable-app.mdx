# Installable app

## Description

The House App can be installed as an app on supported desktop and mobile devices. Installation adds it to the device's app launcher and enables app-style access outside a normal browser tab. On supported platforms, the installed app can also receive device notifications.

## Install the app

1. Open **Account Settings**.
2. Select **Install as App for Notifications**.
3. Follow the browser or device prompt.
4. Open The House App from the device's home screen, dock, or app launcher.

If the browser cannot show an automatic installation prompt, the button opens the manual installation guide instead.

## After installation

Return to **Account Settings** and select **Manage Notifications** to set up device alerts. Installing the app does not turn notifications on by itself.
