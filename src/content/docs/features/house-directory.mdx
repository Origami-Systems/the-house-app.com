# House directory

## Description

The house directory lists the people assigned to a selected house. Users can use it to see who belongs to the house and identify fellow members, student leaders, and staff connected to it.

## How to use it

1. Open a house profile.
2. Open that house's **Directory**.
3. Browse the list of people assigned to the house.

The directory is read-only. User assignments are changed by an administrator in **Admin > Users**.
