# Pending point approval

## Description

Pending point approval gives administrators control over point awards that require review. Requests appear in the Admin area, where an administrator can check the submitted details and approve or deny them before they affect the house standings.

## Review a request

1. Open **Admin**.
2. Find the **Pending Points** card. The card only appears when requests are waiting.
3. Select a request to review its house, reason, point amount, and submitter's note.
4. Select **Approve** or **Deny**.

## Buttons and controls

- The **check mark** approves a request directly from the list.
- The **X** denies a request directly from the list.
- **Approve** in the review window accepts the request and applies it.
- **Deny** in the review window rejects the request.

Approved and denied requests leave the pending list after the action succeeds.
