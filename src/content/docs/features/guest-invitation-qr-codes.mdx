# Guest invitation QR codes

## Description

A guest invitation QR code lets people open temporary guest access by scanning a code instead of typing a link. Administrators create the invitation from a guest group and then share the code with the intended participants.

## Open an invitation

1. Open **Admin > Guests**.
2. Select a guest group.
3. Open the invitation you want to share, or create a new invitation first.
4. Check the invitation name and description before distributing it.

## Share the invitation

- Select the invitation link field to copy the URL to the clipboard.
- Select **Download QR Code** to save the code as an image.
- Select **Print QR Code** to open a print-ready page in a new window.

If the print window does not open, allow pop-ups for The House App and try again. Treat the QR code like the invitation link itself. Anyone who receives it may be able to use the guest access while the invitation remains valid.
