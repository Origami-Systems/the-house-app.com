# Support and feedback

## Description

The support forms let users report a problem or suggest an improvement without leaving the app. Bug reports collect a title, description, reproduction steps, extra context, and technical information. Feedback requests ask what the user would like added and why it would be useful.

## Report a bug

1. Open **Account Settings > Report Bug**.
2. Enter a short title.
3. Describe what happened.
4. List the steps that cause the problem.
5. Add any other useful context.
6. Leave **Include technical information** on to attach the browser type, operating system version, and screen size, or turn it off.
7. Select **Submit**.

## Suggest an improvement

1. Open **Account Settings > Give Feedback**.
2. Describe what you would like added.
3. Explain why it would help.
4. Select **Submit**.

Both feedback fields are required even though the second field does not show a required marker.
