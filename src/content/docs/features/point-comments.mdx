# Point comments

## Description

Point comments let users discuss a specific point award or deduction. The organization must allow comments before the comment controls appear.

## Add a comment

1. Open a house's point history.
2. Select the point entry you want to discuss.
3. Open **Options**.
4. Select **Send Comment**.
5. Enter your comment.
6. Select **Send**.

Guest groups cannot post comments. If **Send Comment** is missing, comments may be disabled or your account may not have access.

## Delete a comment

1. Open the three-dot **Actions** menu on your comment.
2. Select **Delete Comment**.
3. Read the warning, then select **Delete Comment** again.

Comment authors and administrators can delete comments. Deleted comments cannot be recovered.
